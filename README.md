# Zoid Gundam Mod — Rusted Warfare Total Conversion

![Launcher Preview](https://github.com/a6407805-alt/Zoid-Gundam-Mod/releases/latest/download/launcher-preview.png)

A Rusted Warfare total conversion mod pack combining **Mobile Suit Gundam**, **Zeon Amphibious Corps**, and **Zoids** with a self-updating, auto-syncing WPF Launcher and Steam Play integration.

## Quick Start (Players)
1. Download **[Zoid-Gundam-Mod.exe](https://github.com/a6407805-alt/Zoid-Gundam-Mod/releases/latest/download/Zoid-Gundam-Mod.exe)** from the latest release.
2. Run `Zoid-Gundam-Mod.exe` — it finds Rusted Warfare (`Steam\steamapps\common\Rusted Warfare`), downloads and installs `Zoid Gundam` into `Rusted Warfare\mods\units\Zoid Gundam`, and creates a `Zoid Gundam Mod` shortcut on your Desktop.
3. Optional: Flip **`STEAM PLAY -> LAUNCHER: ON`** in the top bar so clicking **Play** on Rusted Warfare in Steam automatically opens the launcher first!
4. Click **PLAY** to launch Rusted Warfare through Steam.

## Auto-Sync & Publishing (Owner & Creators)
- **Automatic Folder Sync**: If you have a creator key saved (`%APPDATA%\ZoidGundam\creator-key.txt` or `%APPDATA%\BrokenCharacters\creator-key.txt`), the launcher automatically keeps `Desktop\Zoid Gundam` and `Rusted Warfare\mods\units\Zoid Gundam` in sync, uploads any new or modified unit `.ini` / `.png` / `.gif` files to GitHub `main`, and immediately updates `Zoid-Gundam-Mod.zip` and `release-info.json` on the `latest` release!
- **Creator Panel**: Click **CREATOR** in the top bar to scan your folder, add a commit note, or drag-and-drop a `.zip` / unit folder into **QUICK UPLOAD**.
