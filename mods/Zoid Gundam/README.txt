ZOID GUNDAM MOD (RUSTED WARFARE)
================================
1. Easiest way: Run Zoid-Gundam-Mod.exe (the Launcher). It auto-syncs, auto-updates, installs into Rusted Warfare\mods\units\Zoid Gundam, and launches the game through Steam.
2. Manual way: Run INSTALL.bat in this folder.
3. To undo Steam Play launch options: Flip STEAM PLAY -> LAUNCHER: OFF in the launcher, or run "Restore Steam Play.bat".
